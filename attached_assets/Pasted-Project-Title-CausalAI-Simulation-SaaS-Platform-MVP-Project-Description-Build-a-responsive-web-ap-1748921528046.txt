Project Title:
CausalAI Simulation SaaS Platform MVP

Project Description:
Build a responsive web app (React frontend) where users can:

Upload their CSV data.

Define a causal diagram by connecting variables.

Train a GenAI time-series model using AWS SageMaker.

Simulate intervention/shock scenarios.

View results (trend forecasts + executive summary).

Use AWS services for backend processing, storage, and AI training.

🧠 Required Features
Frontend (React):

Variable input screen.

Visual causal diagram builder (drag-and-drop).

Data upload (CSV, max size: 2MB in free plan).

Scenario simulator (intervention or shock).

Result screen with:

Graphs (Plotly/Chart.js).

Executive summary (generated by AWS Bedrock or SageMaker).

Variable-by-variable analysis (premium plan only).

Backend (Python FastAPI or Node.js):

Handles file upload.

Parses user input (causal structure).

Sends data to AWS for:

Model training (via SageMaker).

Storage (S3).

Execution (Lambda functions).

Returns prediction and summary.

AWS Services:

S3 – Store uploaded data and results.

SageMaker – Fine-tune foundation model per user data.

Bedrock (Claude or Titan) – Optional, for summary generation.

DynamoDB / RDS – Store user metadata and causal graphs.

Lambda + API Gateway – For invoking tasks (train, predict, simulate).

CloudWatch – Logs and monitoring.

Authentication (Optional for MVP):

Use AWS Cognito or simple JWT for free/paid tier access.
